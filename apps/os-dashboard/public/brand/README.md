# nakharax.io brand assets

Source of truth for the current SVG logo direction.

Figma: https://www.figma.com/design/czL6EHuiZJhVS4SnfG5aUk

## Files

- `nakharax-mark.svg` - primary mark on a light surface.
- `nakharax-mark-transparent.svg` - transparent mark for controlled light backgrounds.
- `nakharax-token.svg` - square dark token/app icon, best for dark UI chrome.
- `nakharax-lockup.svg` - horizontal mark plus wordmark.
- `nakharax-mark-mono.svg` - one-color fallback.

## Tokens

- Graphite: `#111318`
- Mono foreground: `#F8FAFC` / `#0F172A`
- Mono secondary: `#64748B` / `#334155`
- Light surface: `#F7F9FB`

The current mark is a monochrome `N + X` compute monogram: the `N` is the Nakharax node path, the diagonal route is workload routing, the base line is settlement, and the surrounding hex frame is the worker mesh.
